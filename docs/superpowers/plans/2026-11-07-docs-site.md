# Documentation Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a seven-language user guide, privacy policy and support page at `https://nfcarchiver.com/docs/` and on GitHub Pages, and make the app's privacy screen a summary that links to it.

**Architecture:**
- The sources are MkDocs Material pages in `site-docs/`, one folder per language, built by `mkdocs-static-i18n`.
- A manual workflow builds the same commit twice, once per base URL. It then deploys one tree to GitHub Pages and the other to the `docs/` prefix of the `nfcarchiver.com` bucket, and verifies a build marker on both.
- The Flutter privacy screen shows a short localized summary, plus a button that opens the per-locale site URL through `url_launcher`.

**Tech Stack:** MkDocs 1.6, mkdocs-material 9, mkdocs-static-i18n 1.3, Python 3.12 on CI, GitHub Actions (Pages and OIDC to AWS), Flutter 3.44.8, url_launcher.

**Spec:** `docs/superpowers/specs/2026-11-07-docs-site-design.md`

## Global Constraints

- **Languages:** exactly the app's: en, ru, tr, uk, ka, pl, be. The list is derived from `lib/l10n/app_*.arb`, never typed twice.
- **URLs:** English at the root (`/docs/privacy/`), others under their code (`/docs/ru/privacy/`).
  - Apple gets `https://nfcarchiver.com/docs/privacy/` and `https://nfcarchiver.com/docs/support/`.
- **Contact:** `support@nfcarchiver.com`.
- **English is authoritative** for the privacy policy. Each translation says so in one line.
- **Screenshots:** English, shared by every language, in `site-docs/docs/assets/screenshots/`.
- **The site loads nothing third-party:** `theme.font: false`, no analytics, search is local.
- **Public repo hygiene:** never commit, log or publish the AWS account ID, role ARN, CloudFront distribution ID, or the name or contents of the private infrastructure repo, including which other projects share the role. Don't echo `DIST_ID` and don't run `aws sts get-caller-identity` in the new workflow.
- **`deploy-docs.yml` is `workflow_dispatch` only**, from `master`, with a `dry_run` input. Nothing deploys on push.
- **Don't touch** `release.yml` (its single `FLUTTER_VERSION: '3.44.8'` line is read by F-Droid), `deploy-webapp.yml`, the `app/` prefix or any v* tag.
- **Never commit** `ios/Flutter/LocalOverrides.xcconfig.free-team`.
- **Never `git push` a tag, merge a PR, run the real deploy, or upload to TestFlight** without the maintainer asking in that moment.
- **Guide terms must match the app.** UI terms in the guide are copied from that locale's ARB value: `scanTags`, `scanMoreTags`, `chunkAlreadyScanned`, `tagWritten`, `createArchive`, `restoreArchive`, `openFile`, `saveToDevice`, `shareFile`, `rescanTags`, `tryDifferentPassword`, `nfcTagType`, `password`.

## Review Focus

1. **A language that lacks a page:** the language switch would lead to a 404. `check_site.py` fails when any locale folder lacks a page that `en/` has (Task 1).
2. **A deploy pointed at the wrong prefix** (empty, `/`, `app/`, no trailing slash) would delete a neighbouring site through `sync --delete`. The deploy refuses any prefix except one matching `^[a-z0-9-]+/$` that differs from `S3_PREFIX`. The dry run also fails if any planned key falls outside `s3://$BUCKET/$PREFIX` (Task 3).
3. **The Pages copy carrying `/docs/`-absolute links** would break the language switch and the 404 page under `/nfcarchiver/`. `check_site.py --built <dir> --base <path>` fails on any `href`/`src` that starts with `/` but not with the tree's own base path (Tasks 1 and 3).
4. **The app running in a language the docs don't have**, for example a German phone the app falls back from. The privacy link must open English, never `/docs/de/…` (Task 5).
5. **The phone can't open the link** (no browser, or the launch fails). The screen shows a snackbar, and the URL stays visible and selectable, so a reviewer can still reach the policy (Task 5).

- [ ] **Step 1: Workflow skeleton**
  - `on: workflow_dispatch` with a `dry_run` boolean.
  - `permissions: {}`.
  - `concurrency: { group: deploy-docs, cancel-in-progress: false }`.
  - A first step in every job fails unless `github.ref == 'refs/heads/master'`.

- [ ] **Step 2: `build` job**
  - It runs with `permissions: {}`, because pip runs third-party code. It checks out, sets up Python 3.12 and installs with `--require-hashes`.
  - It runs the source checks, then two strict builds with `DOCS_BUILD_SHA=${{ github.sha }}`:
    - `site/main` with the default URL;
    - `site/pages` with `DOCS_SITE_URL=https://mezinster.github.io/nfcarchiver/`.
  - Built-tree checks: `site/main` with `--base /docs/` and `site/pages` with `--base /nfcarchiver/`.
  - Uploads:
    - `site/main` with `actions/upload-artifact` (name `docs-main`);
    - `site/pages` with `actions/upload-pages-artifact`. Use the current major; check with `gh api repos/actions/upload-pages-artifact/releases/latest -q .tag_name`.

- [ ] **Step 3: `deploy-s3` job**
  - It runs with `needs: build`, `environment: production` and `permissions: { id-token: write, contents: read }`.
  - **Guard step:**
    - fail if any of `BUCKET`, `PREFIX` (= `vars.S3_DOCS_PREFIX`) or `DIST_ID` is empty;
    - fail if `PREFIX` doesn't match `^[a-z0-9-]+/$`;
    - fail if `PREFIX == vars.S3_PREFIX`;
    - print only `target s3://$BUCKET/$PREFIX` (no distribution ID).
  - Assume the role with `aws-actions/configure-aws-credentials@v6` and `role-session-name: gha-docs-deploy-${{ github.run_id }}`.
  - **Dry run** (`if: inputs.dry_run`):
    - run `aws s3 sync docs-main/ "s3://$BUCKET/$PREFIX" --delete --dryrun` and print the output;
    - fail if any line names an `s3://` key that doesn't start with `s3://$BUCKET/$PREFIX`;
    - then stop. Every later step is `if: ${{ !inputs.dry_run }}`.
  - **Upload:**
    1. non-HTML first: `sync --delete --exclude '*.html' --cache-control 'public, max-age=3600'`;
    2. then HTML: `sync --delete --exclude '*' --include '*.html' --cache-control 'no-cache' --content-type 'text/html; charset=utf-8'`.
  - **Invalidate** `/${PREFIX}*` and wait with `aws cloudfront wait invalidation-completed`. Log the invalidation ID only.
  - **Verify:**
    - up to 5 tries, 10 s apart;
    - each try runs `curl -fsS` on `${DOCS_BASE_URL}`, `${DOCS_BASE_URL}privacy/`, `${DOCS_BASE_URL}support/` and `${DOCS_BASE_URL}ru/privacy/`;
    - each response must contain `<meta name="nfar-docs-build" content="${{ github.sha }}">`. Use the full 40-character SHA so a collision is impossible.

- [ ] **Step 4: `deploy-pages` job**
  - It runs with `needs: [build, deploy-s3]`, so Pages never runs ahead of the URL Apple has, and `if: ${{ !inputs.dry_run }}`.
  - `environment: { name: github-pages, url: ${{ steps.deployment.outputs.page_url }} }`.
  - `permissions: { pages: write, id-token: write }`.
  - Steps: `actions/deploy-pages` (current major, `id: deployment`), then the same 5-try marker check on `https://mezinster.github.io/nfcarchiver/` and `…/privacy/`.

- [ ] **Step 5: Lint**
  - Run `actionlint .github/workflows/deploy-docs.yml` if it's installed (`brew install actionlint` is fine locally).
  - Otherwise, `python3 -c 'import yaml,sys; yaml.safe_load(open(sys.argv[1]))' .github/workflows/deploy-docs.yml`.
  - Expected: no errors.

- [ ] **Step 6: `site-docs/README.md`**
