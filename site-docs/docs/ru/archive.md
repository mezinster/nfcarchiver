# Архивация файла

Архивация делит файл на чанки и записывает по одному чанку на каждую метку. Понадобится столько пустых (или перезаписываемых) меток, сколько скажет приложение.

## 1. Выберите файл

На главном экране нажмите **Создать архив**. Выберите **Файл** и нажмите, чтобы выбрать файл в системном окне, или выберите **Текст**, чтобы ввести короткий текст. Затем нажмите **Настроить архив**.

## 2. Настройте архив

![Настройки архива: типы меток](../assets/screenshots/android-archive-settings.png){ width="300" }
![Настройки архива: параметры и оценка](../assets/screenshots/android-archive-estimate.png){ width="300" }

- **Тип NFC-метки** — какие метки вы будете записывать. По умолчанию выбран NTAG216. Сколько вмещает каждая, см. в разделе [Типы меток](tag-types.md). Mifare Classic 1K появляется в списке, только если считыватель может его записать (телефон на Android с поддержкой Mifare или [Chameleon Ultra](chameleon.md)).
- **Включить сжатие** (по желанию) — сжатие GZIP. Оно применяется, только если действительно уменьшает данные; уже сжатые файлы (фото, видео, ZIP) почти не уменьшаются.
- **Включить шифрование** (по желанию) — защищает архив шифром AES-256-GCM. Введите **Пароль**. Пароль нигде не хранится: без него архив не восстановить, не потеряйте его.

**Оценка архива** внизу показывает, сколько меток нужно (**Требуется меток**) и сколько байт попадёт на каждую (**Данных на метку**). Это оценка: результат сжатия угадывается заранее.

Нажмите **Начать архивацию**.

## 3. Запишите метки по одной

![Запись на метки](../assets/screenshots/android-write-progress.png){ width="300" }

Для каждой метки:

1. Нажмите **Записать на метку**.
2. Приложите метку к телефону (на iPhone — когда появится окно NFC, см. [На iPhone](iphone.md)).
3. Дождитесь сообщения **Метка записана!** и уберите метку.

Полоса прогресса считает записанные метки. После последней появится **Архивация завершена!**.

Потом метки можно сканировать в любом порядке, так что нумеровать их не нужно. Но храните их вместе: для восстановления нужна каждая.

!!! warning "Пропустить эту метку"
    **Пропустить эту метку** переходит к следующему чанку, *не записывая* текущий. Архив с пропущенным чанком не восстановить: записать пропущенный чанк позже нельзя. Чтобы получить восстановимый архив, придётся заархивировать файл заново с самого начала.

## Если метка слишком мала { #if-a-tag-is-too-small }

Настоящие метки иногда дают чуть меньше места, чем обещает их тип. Если чанк не помещается, приложение показывает **Метка слишком мала** с объёмом метки и объёмом чанка:

- Если ещё ни одна метка не записана, можно нажать **Перенастроить**: приложение разобьёт данные на чанки поменьше, подходящие для этой метки, и скажет, сколько меток теперь нужно.
- Иначе (или если хотите) нажмите **Использовать другую метку** и приложите метку побольше.

После записи первой метки архив перенастроить уже нельзя.

Если приложить метку другого типа, чем выбран (например, карту Mifare Classic при выбранном NTAG216), приложение об этом скажет; вернитесь назад и измените **Тип NFC-метки**.
