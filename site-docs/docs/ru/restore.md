# Восстановление файла

Чтобы восстановить файл, отсканируйте все метки архива. Порядок не важен.

## 1. Отсканируйте метки

На главном экране нажмите **Восстановить архив**. Откроется экран **Сканирование меток**, и сканирование начнётся.

![Сканирование меток](../assets/screenshots/android-scan.png){ width="300" }

*Снимок сделан в эмуляторе без NFC, отсюда предупреждение. Два архива внизу подготовлены для скриншота.*

Прикладывайте метки к телефону по очереди (на iPhone — одно окно NFC на метку, см. [На iPhone](iphone.md)):

- Новая метка показывает **Найден новый чанк!** и свой номер, например «Чанк 3 из 8».
- Уже отсканированная метка показывает **Дубликат чанка** и пропускается. На iPhone окно закрывается красным восклицательным знаком с сообщением «Чанк 3 из 8 уже отсканирован».

В списке **Архивы в процессе** — все архивы, которые вы начали сканировать, и сколько их меток уже есть (например, 2/4). Прогресс сохраняется: можно уйти и вернуться позже, чтобы досканировать остальное. Метки разных архивов можно перемешивать — каждая попадёт в свой архив.

Чтобы убрать незаконченный архив из списка, нажмите его ✕. Значок корзины вверху очищает весь список.

## 2. Восстановите

Когда отсканирована последняя метка, приложение показывает **Все чанки получены!**.

- **Имя файла** (по желанию): оставьте пустым, чтобы использовать исходное имя.
- Если архив зашифрован («Этот архив зашифрован»), введите **Пароль**.

Нажмите **Восстановить архив**. Если нужно сначала что-то досканировать, **Сканировать ещё метки** вернёт назад.

Сюда же можно попасть, нажав на готовый архив (с галочкой) в списке **Архивы в процессе**.

## 3. Используйте восстановленный файл

![Архив восстановлен](../assets/screenshots/android-restore-complete.png){ width="300" }

**Архив восстановлен!** показывает имя файла. К нему добавляется короткая часть идентификатора архива, чтобы файлы разных архивов не перезаписывали друг друга. Файл хранится внутри приложения, другие приложения его не видят. Чтобы им воспользоваться:

- **Открыть** — открывает файл в приложении, которое умеет работать с таким типом.
- **Сохранить на устройство** — открывает системное окно сохранения (по умолчанию папка «Загрузки»), чтобы сохранить копию вне приложения.
- **Поделиться файлом** — отправляет файл в другое приложение.

Восстановленные файлы также видны в разделе **Архивированные файлы** на главном экране. Архив с текстом показывает сам текст и кнопку, чтобы его скопировать.

## Если что-то пошло не так

- **Неверный пароль**: приложение сообщает (по-английски) "Decryption failed: wrong password or corrupted data". Нажмите **Попробовать другой пароль** и введите его снова.
- **Обнаружено повреждение данных**: чанк на одной из меток не прошёл проверку контрольной суммы (CRC). Нажмите **Пересканировать 1 метку(и)** (число бывает разным) и снова отсканируйте указанные метки; удачное чтение заменит повреждённый чанк.

Подробнее — в разделе [Решение проблем](troubleshooting.md).
