# Политика конфиденциальности

*Юридически значим английский текст: [Privacy policy](../../privacy/).*

**NFC Archiver** · Обновлено: 11 ноября 2026 г.

## Коротко

NFC Archiver работает полностью офлайн. Приложение не собирает и не отправляет персональные данные, в нём нет аналитики, рекламы и слежки. Оно использует NFC, Bluetooth (только для связи с принадлежащим вам считывателем Chameleon Ultra) и файлы, которые вы выбираете сами.

## Сбор данных

**Мы не собираем никаких данных.** В частности:

- персональная информация не собирается;
- нет аналитики использования и отслеживания;
- отчёты о сбоях никуда не отправляются;
- нет файлов cookie и идентификаторов;
- нет рекламных и маркетинговых данных.

## NFC

NFC используется только для чтения и записи данных на физические NFC-метки, которые вы подносите к телефону. Все операции с NFC выполняются локально, по сети ничего не передаётся.

## Bluetooth

Bluetooth используется только для подключения к принадлежащему вам считывателю Chameleon Ultra, чтобы приложение могло читать и записывать карты Mifare Classic через него. Соединение локальное, между телефоном и считывателем. Из-за него никакие данные не покидают ваше устройство, а местоположение через Bluetooth приложение не определяет.

## Файлы

Файлы, которые вы архивируете, обрабатываются полностью на вашем устройстве. Файл:

- читается с устройства через системное окно выбора файлов;
- по желанию сжимается (GZIP) на устройстве;
- по желанию шифруется (AES-256-GCM) на устройстве;
- делится на фрагменты и записывается на NFC-метки.

Данные файлов никогда не загружаются, не передаются и не отправляются на серверы. Восстановленные файлы сохраняются в закрытом хранилище приложения и покидают его, только когда вы выбираете «Открыть», «Сохранить на устройство» или «Поделиться». Незавершённое восстановление (уже отсканированные фрагменты) хранится в закрытом хранилище приложения, пока вы его не завершите или не удалите из списка.

## Шифрование

Когда вы включаете шифрование:

- пароль используется на устройстве для получения ключа шифрования (PBKDF2);
- пароль никогда не сохраняется, не записывается в журнал и не передаётся;
- шифрование и расшифровка выполняются полностью на вашем устройстве.

Если вы забудете пароль, никто не сможет восстановить файл, в том числе мы.

## Диагностические журналы

Приложение ведёт на вашем устройстве диагностический журнал: что оно делало и какие ошибки встретило, чтобы можно было разобраться с проблемами. Он хранится в небольшом файле, который автоматически ротируется, и никогда не содержит ваши файлы, имена файлов или пароли. Он никуда не отправляется. Журнал покидает устройство, только если вы сами им поделитесь — из раздела **О приложении → Журнал диагностики**, где его также можно очистить в любой момент.

## Сторонние сервисы

NFC Archiver **не использует сторонние сервисы**: ни аналитики, ни облачного хранилища, ни удалённых серверов, ни интеграций с социальными сетями.

## Разрешения

Все разрешения, которые объявляет приложение, и их назначение.

**Android**

- **NFC** (`NFC`): чтение и запись NFC-меток.
- **Bluetooth** (`BLUETOOTH_SCAN`, `BLUETOOTH_CONNECT`, а в старых версиях Android ещё `BLUETOOTH` и `BLUETOOTH_ADMIN`): только для поиска и подключения принадлежащего вам считывателя Chameleon Ultra.
- **Хранилище** (`READ_EXTERNAL_STORAGE`, `WRITE_EXTERNAL_STORAGE`): только в старых версиях Android, для чтения выбранных вами файлов и сохранения восстановленных. В современных версиях файлы выбираются через системное окно выбора файлов.

**iPhone**

- **NFC** (`NFCReaderUsageDescription`): чтение и запись NFC-меток.
- **Bluetooth** (`NSBluetoothAlwaysUsageDescription`): только для подключения принадлежащего вам считывателя Chameleon Ultra.

## Этот сайт

Сайт документации не устанавливает файлы cookie, не использует аналитику и не загружает сторонние шрифты и скрипты. Поиск работает локально в вашем браузере.
