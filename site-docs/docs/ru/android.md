# На Android

Телефон на Android с NFC напрямую записывает и читает метки **NTAG213, NTAG215 и NTAG216**. **Mifare Classic 1K** он тоже может записывать и читать напрямую, но только если его NFC-чип поддерживает Mifare Classic (функция NXP Mifare). Так умеют не все телефоны: у многих NFC-чипов других производителей её нет.

Приложение проверяет это само. Если телефон не умеет работать с Mifare Classic, **Mifare Classic 1K** просто нет в списке типов меток. [Chameleon Ultra](chameleon.md) добавляет его на любом телефоне.

![Главный экран](../assets/screenshots/android-home.png){ width="300" }

*Главный экран (скриншоты на английском). Снимок сделан в эмуляторе без NFC, поэтому видно предупреждение «NFC недоступен».*

## Перед началом

- **Включите NFC** в настройках телефона. Если NFC выключен (или его нет), на главном экране написано **NFC недоступен**.
- **Найдите антенну.** Где находится антенна NFC, зависит от телефона; у многих моделей — на задней стороне, ближе к верху. Если ничего не происходит, медленно поводите меткой по задней стороне телефона.
- Держите метку неподвижно, пока приложение не отреагирует. Метка, убранная посреди записи или чтения, — самая частая причина сбоя.

## Как это работает на Android

Системного окна на Android нет: ход работы показывает экран самого приложения.

- При **записи** нажмите **Записать на метку** и приложите метку к телефону. **Метка записана!** подтверждает запись. Уберите метку и снова нажмите **Записать на метку** для следующей.
- При **сканировании** прикладывайте метки одну за другой. Каждая новая показывает **Найден новый чанк!**; уже отсканированная — **Дубликат чанка**.

Если приложить карту Mifare Classic к телефону без её поддержки, приложение сообщит (пока по-английски): "This looks like a Mifare Classic card. Your phone's NFC chip can't read them." («Похоже, это карта Mifare Classic. NFC-чип вашего телефона не может их читать.»)
