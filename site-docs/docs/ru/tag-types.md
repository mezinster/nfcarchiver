# Типы меток

NFC Archiver записывает метки этих типов. Выберите свой в поле **Тип NFC-метки** при [архивации файла](archive.md).

## Ёмкость

| Тип метки | Ёмкость | Данных на метку |
|---|---|---|
| NTAG213 | 144 байта | 68 байт |
| NTAG215 | 504 байта | 428 байт |
| NTAG216 | 888 байт | 812 байт |
| Mifare Classic 1K | 752 байта | 720 байт |

**Ёмкость** — сколько памяти метки приложение считает доступной. **Данных на метку** — часть, которая остаётся для вашего файла: каждая метка несёт ещё 32-байтовый заголовок NFAR с контрольной суммой, а на метках NTAG чанк к тому же упакован в запись NDEF (приложение резервирует под неё 44 байта). Mifare Classic 1K хранит чанк прямо в блоках данных, поэтому вычитается только заголовок. Это же число приложение показывает как **Данных на метку** в оценке архива.

## Сколько меток нужно файлу, примерно

Без сжатия и без нескольких байт на имя файла:

| Размер файла | NTAG213 | NTAG215 | NTAG216 | Mifare Classic 1K |
|---|---|---|---|---|
| 1 КБ | 16 | 3 | 2 | 2 |
| 10 КБ | 151 | 24 | 13 | 15 |
| 100 КБ | 1 506 | 240 | 127 | 143 |

Шифрование добавляет 44 байта на весь архив, а не на каждую метку. NFC-метки маленькие: архивы лучше подходят для небольших файлов — текста, ключей, файлов настроек, небольших документов. В архиве может быть не больше 65 535 чанков.

Если настоящая метка сообщает меньше места, чем положено её типу, приложение предложит перенастроить архив до записи первой метки (см. [Если метка слишком мала](archive.md#if-a-tag-is-too-small)).

В списке приложения есть также MIFARE Ultralight (48 байт — слишком мало для чанка архива), MIFARE Ultralight C (144 байта) и Generic 1KB (1024 байта).

## Какой считыватель что поддерживает

| | NTAG213/215/216 | Mifare Classic 1K |
|---|---|---|
| Встроенный NFC iPhone | Да | Нет |
| Встроенный NFC телефона на Android | Да | Только если NFC-чип телефона поддерживает Mifare Classic |
| [Chameleon Ultra](chameleon.md) (с iPhone или Android) | Да | Да |

Приложение предлагает Mifare Classic 1K, только когда активный считыватель может его записать. Если отключить Chameleon при выбранном Mifare Classic 1K, а телефон с ним не работает, выбор вернётся на NTAG216.
