# NFC Archiver

NFC Archiver захоўвае файл на некалькіх NFC-метках і пазней аднаўляе яго: меткі можна сканаваць у любым парадку. Ёсць неабавязковае сцісканне і шыфраванне паролем, усё працуе цалкам афлайн.
