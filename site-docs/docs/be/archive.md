# Архіваванне файла

Архіваванне дзеліць файл на фрагменты і запісвае па адным фрагменце на кожную метку. Спатрэбіцца столькі пустых (або перазапісвальных) метак, колькі скажа праграма.

## 1. Выберыце файл

На галоўным экране націсніце **Стварыць архіў**. Выберыце **Файл** і націсніце, каб выбраць файл у сістэмным акне, або выберыце **Тэкст**, каб увесці кароткі тэкст. Потым націсніце **Наладзіць архіў**.

## Архівацыя фота { #archiving-a-photo }

Націсніце **Выбраць фота** на экране стварэння архіва або адпраўце фота з «Фота», Галерэі ці «Файлаў» у NFC Archiver (адпраўлены файл, што не з'яўляецца фота, адразу адкрывае налады архіва). Калі адправіць некалькі аб'ектаў, выкарыстоўваецца толькі першы. На iPhone, калі праграма не адкрылася сама пасля адпраўкі, адкрыйце яе — фота будзе падхоплена.

Экран **Аптымізацыя фота** памяншае фота пад вашы меткі. У полі **Колькі метак** лепшая якасць, што змяшчаецца, падбіраецца аўтаматычна; націсніце **Уручную**, каб выбраць лік самастойна (і **Вярнуць аўта**, каб вярнуцца). Націсніце **Прапусціць (пакінуць арыгінал)**, каб заархіваваць фота без змен, або **Працягнуць**, каб прыняць вынік.

З аптымізаванага фота выдаляюцца даныя пра месцазнаходжанне і камеру.

## 2. Наладзьце архіў

![Налады архіва: тыпы метак](../assets/screenshots/android-archive-settings.png){ width="300" }
![Налады архіва: параметры і ацэнка](../assets/screenshots/android-archive-estimate.png){ width="300" }

- **Тып NFC-меткі** — якія меткі вы будзеце запісваць. Па змаўчанні выбраны NTAG216. Колькі змяшчае кожная, гл. у раздзеле [Тыпы метак](tag-types.md). Mifare Classic 1K з'яўляецца ў спісе, толькі калі счытвальнік можа яго запісаць (тэлефон на Android з падтрымкай Mifare або [Chameleon Ultra](chameleon.md)).
- **Уключыць сціск** (па жаданні) — сціск GZIP. Ён ужываецца, толькі калі сапраўды памяншае даныя; ужо сціснутыя файлы (фота, відэа, ZIP) амаль не памяншаюцца.
- **Уключыць шыфраванне** (па жаданні) — абараняе архіў шыфрам AES-256-GCM. Увядзіце **Пароль**. Пароль нідзе не захоўваецца: без яго архіў не аднавіць, не страціце яго.

**Ацэнка архіва** ўнізе паказвае, колькі метак трэба (**Патрэбна метак**) і колькі байтаў трапіць на кожную (**Даных на метку**). Гэта ацэнка: вынік сціску адгадваецца загадзя.

Націсніце **Пачаць архівацыю**.

## 3. Запішыце меткі па адной

![Запіс на меткі](../assets/screenshots/android-write-progress.png){ width="300" }

Для кожнай меткі:

1. Націсніце **Запісаць на метку**.
2. Прыкладзіце метку да тэлефона (на iPhone — калі з'явіцца акно NFC, гл. [На iPhone](iphone.md)).
3. Дачакайцеся паведамлення **Метка запісана!** і прыбярыце метку.

Палоска прагрэсу лічыць запісаныя меткі. Пасля апошняй з'явіцца **Архівацыя завершана!**.

Потым меткі можна сканаваць у любым парадку, так што нумараваць іх не трэба. Але захоўвайце іх разам: для аднаўлення патрэбна кожная.

!!! warning "Прапусціць гэту метку"
    **Прапусціць гэту метку** пераходзіць да наступнага фрагмента, *не запісваючы* бягучы. Архіў з прапушчаным фрагментам не аднавіць: запісаць прапушчаны фрагмент пазней нельга. Каб атрымаць архіў, які можна аднавіць, давядзецца заархіваваць файл нанова з самага пачатку.

## Калі метка занадта малая { #if-a-tag-is-too-small }

Сапраўдныя меткі часам даюць крыху менш месца, чым абяцае іх тып. Калі фрагмент не змяшчаецца, праграма паказвае **Метка занадта малая** з аб'ёмам меткі і аб'ёмам фрагмента:

- Калі яшчэ ніводная метка не запісана, можна націснуць **Пераналадзіць**: праграма разаб'е даныя на меншыя фрагменты, якія падыходзяць для гэтай меткі, і скажа, колькі метак цяпер трэба.
- Інакш (або калі хочаце) націсніце **Выкарыстаць іншую метку** і прыкладзіце большую метку.

Пасля запісу першай меткі архіў пераналадзіць ужо нельга.

Калі прыкласці метку іншага тыпу, чым выбрана (напрыклад, карту Mifare Classic пры выбраным NTAG216), праграма пра гэта скажа; вярніцеся назад і змяніце **Тып NFC-меткі**.
