# Аднаўленне файла

Каб аднавіць файл, адсканіруйце ўсе меткі архіва. Парадак не важны.

## 1. Адсканіруйце меткі

На галоўным экране націсніце **Аднавіць архіў**. Адкрыецца экран **Сканаванне метак**, і сканаванне пачнецца.

![Сканаванне метак](../assets/screenshots/android-scan.png){ width="300" }

*Здымак зроблены ў эмулятары без NFC, адсюль папярэджанне. Два архівы ўнізе падрыхтаваны для здымка.*

Прыкладвайце меткі да тэлефона па чарзе (на iPhone — адно акно NFC на метку, гл. [На iPhone](iphone.md)):

- Новая метка паказвае **Знойдзены новы фрагмент!** і свой нумар, напрыклад «Фрагмент 3 з 8».
- Ужо адсканаваная метка паказвае **Дублікат фрагмента** і прапускаецца. На iPhone акно закрываецца чырвоным клічнікам з паведамленнем «Фрагмент 3 з 8 ужо адсканаваны».

У спісе **Архівы ў працэсе** — усе архівы, якія вы пачалі сканаваць, і колькі іх метак ужо ёсць (напрыклад, 2/4). Прагрэс захоўваецца: можна сысці і вярнуцца пазней, каб дасканаваць астатняе. Меткі розных архіваў можна перамешваць — кожная трапіць у свой архіў.

Каб прыбраць незавершаны архіў са спісу, націсніце яго ✕. Значок кошыка ўверсе ачышчае ўвесь спіс.

## 2. Аднавіце

Калі адсканавана апошняя метка, праграма паказвае **Усе фрагменты атрыманы!**.

- **Імя файла** (па жаданні): пакіньце пустым, каб выкарыстаць зыходнае імя.
- Калі архіў зашыфраваны («Гэты архіў зашыфраваны»), увядзіце **Пароль**.

Націсніце **Аднавіць архіў**. Калі трэба спачатку штосьці дасканаваць, **Сканаваць яшчэ меткі** верне назад.

Сюды ж можна трапіць, націснуўшы на гатовы архіў (з галачкай) у спісе **Архівы ў працэсе**.

## 3. Выкарыстайце адноўлены файл

![Архіў адноўлены](../assets/screenshots/android-restore-complete.png){ width="300" }

**Архіў адноўлены!** паказвае імя файла. Да яго дадаецца кароткая частка ідэнтыфікатара архіва, каб файлы розных архіваў не перазапісвалі адзін аднаго. Файл захоўваецца ўнутры праграмы, іншыя праграмы яго не бачаць. Каб ім скарыстацца:

- **Адкрыць** — адкрывае файл у праграме, якая ўмее працаваць з такім тыпам.
- **Захаваць на прыладу** — адкрывае сістэмнае акно захавання (па змаўчанні папка «Спампоўкі»), каб захаваць копію па-за праграмай.
- **Падзяліцца файлам** — адпраўляе файл у іншую праграму.

Адноўленыя файлы таксама відаць у раздзеле **Архіваваныя файлы** на галоўным экране. Архіў з тэкстам паказвае сам тэкст і кнопку, каб яго скапіраваць.

## Калі штосьці пайшло не так

- **Няправільны пароль**: праграма паведамляе (па-англійску) "Decryption failed: wrong password or corrupted data". Націсніце **Паспрабаваць іншы пароль** і ўвядзіце яго зноў.
- **Выяўлена пашкоджанне даных**: фрагмент на адной з метак не прайшоў праверку кантрольнай сумы (CRC). Націсніце **Перасканаваць 1 метку(і)** (лік бывае розны) і зноў адсканіруйце названыя меткі; удалае чытанне заменіць пашкоджаны фрагмент.

Падрабязней — у раздзеле [Вырашэнне праблем](troubleshooting.md).
