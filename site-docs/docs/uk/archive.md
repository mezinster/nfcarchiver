# Архівація файлу

Архівація ділить файл на чанки і записує по одному чанку на кожну мітку. Знадобиться стільки порожніх (або перезаписуваних) міток, скільки скаже застосунок.

## 1. Виберіть файл

На головному екрані натисніть **Створити архів**. Виберіть **Файл** і натисніть, щоб вибрати файл у системному вікні, або виберіть **Текст**, щоб ввести короткий текст. Потім натисніть **Налаштувати архів**.

## Архівація фото { #archiving-a-photo }

Натисніть **Вибрати фото** на екрані створення архіву або надішліть фото з «Фото», Галереї чи «Файлів» у NFC Archiver (надісланий файл, що не є фото, одразу відкриває налаштування архіву). Якщо надіслати кілька об'єктів, використовується лише перший. На iPhone, якщо застосунок не відкрився сам після надсилання, відкрийте його — фото буде підхоплено.

Екран **Оптимізація фото** зменшує фото під ваші мітки. У полі **Скільки міток** задайте, скільки міток може зайняти фото; найкраща якість, що в них вміщується, добирається автоматично. Щоб задати розмір і якість самостійно, виберіть їх у розділі **Вручну** (натисніть **Повернути авто**, щоб повернутися). Натисніть **Пропустити (залишити оригінал)**, щоб заархівувати фото без змін, або **Продовжити**, щоб прийняти результат.

Із оптимізованого фото видаляються дані про місцезнаходження та камеру.

## 2. Налаштуйте архів

![Налаштування архіву: типи міток](../assets/screenshots/android-archive-settings.png){ width="300" }
![Налаштування архіву: параметри й оцінка](../assets/screenshots/android-archive-estimate.png){ width="300" }

- **Тип NFC-мітки** — які мітки ви записуватимете. Типово вибрано NTAG216. Скільки вміщує кожна, див. у розділі [Типи міток](tag-types.md). Mifare Classic 1K з'являється у списку, лише якщо зчитувач може його записати (телефон на Android з підтримкою Mifare або [Chameleon Ultra](chameleon.md)).
- **Увімкнути стиснення** (за бажанням) — стиснення GZIP. Воно застосовується, лише якщо справді зменшує дані; уже стиснені файли (фото, відео, ZIP) майже не зменшуються.
- **Увімкнути шифрування** (за бажанням) — захищає архів шифром AES-256-GCM. Введіть **Пароль**. Пароль ніде не зберігається: без нього архів не відновити, не загубіть його.

**Оцінка архіву** внизу показує, скільки міток потрібно (**Потрібно міток**) і скільки байтів потрапить на кожну (**Даних на мітку**). Це оцінка: результат стиснення вгадується заздалегідь.

Натисніть **Почати архівацію**.

## 3. Запишіть мітки по одній

![Запис на мітки](../assets/screenshots/android-write-progress.png){ width="300" }

Для кожної мітки:

1. Натисніть **Записати на мітку**.
2. Прикладіть мітку до телефону (на iPhone — коли з'явиться вікно NFC, див. [На iPhone](iphone.md)).
3. Дочекайтеся повідомлення **Мітку записано!** і приберіть мітку.

Смуга прогресу рахує записані мітки. Після останньої з'явиться **Архівацію завершено!**.

Потім мітки можна сканувати в будь-якому порядку, тож нумерувати їх не потрібно. Але зберігайте їх разом: для відновлення потрібна кожна.

!!! warning "Пропустити цю мітку"
    **Пропустити цю мітку** переходить до наступного чанку, *не записуючи* поточний. Архів із пропущеним чанком не відновити: записати пропущений чанк пізніше неможливо. Щоб отримати архів, який можна відновити, доведеться заархівувати файл заново з самого початку.

## Якщо мітка замала { #if-a-tag-is-too-small }

Справжні мітки іноді дають трохи менше місця, ніж обіцяє їхній тип. Якщо чанк не вміщується, застосунок показує **Мітка занадто мала** з обсягом мітки й обсягом чанку:

- Якщо ще жодну мітку не записано, можна натиснути **Переналаштувати**: застосунок розіб'є дані на менші чанки, що підходять для цієї мітки, і скаже, скільки міток тепер потрібно.
- Інакше (або якщо хочете) натисніть **Використати іншу мітку** і прикладіть більшу мітку.

Після запису першої мітки архів переналаштувати вже не можна.

Якщо прикласти мітку іншого типу, ніж вибрано (наприклад, картку Mifare Classic при вибраному NTAG216), застосунок про це скаже; поверніться назад і змініть **Тип NFC-мітки**.
