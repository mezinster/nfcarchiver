# Відновлення файлу

Щоб відновити файл, відскануйте всі мітки архіву. Порядок не важливий.

## 1. Відскануйте мітки

На головному екрані натисніть **Відновити архів**. Відкриється екран **Сканування міток**, і сканування почнеться.

![Сканування міток](../assets/screenshots/android-scan.png){ width="300" }

*Знімок зроблено в емуляторі без NFC, звідси попередження. Два архіви внизу підготовлено для знімка.*

Прикладайте мітки до телефону по черзі (на iPhone — одне вікно NFC на мітку, див. [На iPhone](iphone.md)):

- Нова мітка показує **Знайдено новий чанк!** і свій номер, наприклад «Чанк 3 з 8».
- Уже відсканована мітка показує **Дублікат чанку** і пропускається. На iPhone вікно закривається хрестиком із повідомленням «Чанк 3 з 8 вже відскановано».

У списку **Архіви в процесі** — усі архіви, які ви почали сканувати, і скільки їхніх міток уже є (наприклад, 2/4). Прогрес зберігається: можна піти й повернутися пізніше, щоб досканувати решту. Мітки різних архівів можна перемішувати — кожна потрапить до свого архіву.

Щоб прибрати незавершений архів зі списку, натисніть його ✕. Значок кошика вгорі очищає весь список.

## 2. Відновіть

Коли відскановано останню мітку, застосунок показує **Усі чанки отримано!**.

- **Ім'я файлу** (за бажанням): залиште порожнім, щоб використати початкове ім'я.
- Якщо архів зашифровано («Цей архів зашифровано»), введіть **Пароль**.

Натисніть **Відновити архів**. Якщо треба спершу щось досканувати, **Сканувати ще мітки** поверне назад.

Сюди ж можна потрапити, натиснувши на готовий архів (з галочкою) у списку **Архіви в процесі**.

## 3. Використайте відновлений файл

![Архів відновлено](../assets/screenshots/android-restore-complete.png){ width="300" }

**Архів відновлено!** показує ім'я файлу. До нього додається коротка частина ідентифікатора архіву, щоб файли різних архівів не перезаписували один одного. Файл зберігається всередині застосунку, інші застосунки його не бачать. Щоб ним скористатися:

- **Відкрити** — відкриває файл у застосунку, що вміє працювати з таким типом.
- **Зберегти на пристрій** — відкриває системне вікно збереження (типово папка «Завантаження»), щоб зберегти копію поза застосунком.
- **Поділитися файлом** — надсилає файл до іншого застосунку.

Відновлені файли також видно в розділі **Архівовані файли** на головному екрані. Архів із текстом показує сам текст і кнопку, щоб його скопіювати.

## Якщо щось пішло не так

- **Неправильний пароль**: застосунок повідомляє (англійською) "Decryption failed: wrong password or corrupted data". Натисніть **Спробувати інший пароль** і введіть його знову.
- **Виявлено пошкодження даних**: чанк на одній із міток не пройшов перевірку контрольної суми (CRC). Натисніть **Пересканувати 1 мітку(и)** (число буває різним) і знову відскануйте вказані мітки; вдале читання замінить пошкоджений чанк.
