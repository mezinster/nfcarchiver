# Pomoc

Napisz na [support@nfcarchiver.com](mailto:support@nfcarchiver.com) lub zgłoś problem na [GitHubie](https://github.com/mezinster/nfcarchiver/issues).

## Co podać

Abyśmy mogli odtworzyć problem, podaj proszę:

- model telefonu;
- wersję systemu operacyjnego (iOS lub Android);
- wersję aplikacji, widoczną na dole ekranu głównego;
- typ używanych tagów (NTAG213, NTAG215, NTAG216 lub Mifare Classic 1K) oraz informację, czy używasz Chameleon Ultra;
- co zrobiłeś i co stało się zamiast oczekiwanego efektu.

Prosimy nie przesyłać zawartości archiwizowanych plików ani haseł.
