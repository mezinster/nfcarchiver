# NFC Archiver

NFC Archiver zapisuje plik na kilku tagach NFC i później go odtwarza: tagi można skanować w dowolnej kolejności. Dostępna jest opcjonalna kompresja i szyfrowanie hasłem, a całość działa w pełni offline.
