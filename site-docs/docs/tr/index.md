# NFC Archiver

NFC Archiver, bir dosyayı birkaç NFC etiketine dağıtarak saklar ve etiketleri herhangi bir sırada tarayarak sonradan geri yükler. İsteğe bağlı sıkıştırma ve parola ile şifreleme sunar, tamamen çevrimdışı çalışır.
