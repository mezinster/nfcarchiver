# ფაილის დაარქივება

დაარქივება ფაილს ნაწილებად ყოფს და თითო ტეგზე თითო ნაწილს წერს. დაგჭირდებათ იმდენი ცარიელი (ან გადასაწერი) ტეგი, რამდენსაც აპი გეტყვით.

## 1. აირჩიეთ ფაილი

მთავარ ეკრანზე შეეხეთ **არქივის შექმნა**-ს. აირჩიეთ **ფაილი** და შეეხეთ, რომ სისტემური ფაილების ამრჩევით აირჩიოთ ფაილი, ან აირჩიეთ **ტექსტი**, რომ მოკლე ტექსტი აკრიფოთ. შემდეგ შეეხეთ **არქივის კონფიგურაცია**-ს.

## ფოტოს დაარქივება { #archiving-a-photo }

არქივის შექმნის ეკრანზე შეეხეთ **ფოტოს არჩევა**-ს ან გააზიარეთ ფოტო Photos-იდან, Gallery-დან ან Files-იდან NFC Archiver-ში (ფაილი, რომელიც ფოტო არ არის, პირდაპირ არქივის პარამეტრებს ხსნის). რამდენიმე ელემენტის გაზიარებისას მხოლოდ პირველი გამოიყენება. iPhone-ზე, თუ გაზიარების შემდეგ აპი თავისით არ გაიხსნა, გახსენით ის და ფოტო აიღება.

**ფოტოს ოპტიმიზაცია** ეკრანი ფოტოს ამცირებს თქვენს ტეგებზე მისაყვანად. **გამოსაყენებელი ტეგები**-ს ქვეშ საუკეთესო ხარისხი, რომელიც ეტევა, ავტომატურად მოიძებნება; რაოდენობის თვითონ ასარჩევად შეეხეთ **ხელით**-ს (დასაბრუნებლად — ავტომატურზე დაბრუნებას). ფოტოს უცვლელად დასაარქივებლად შეეხეთ **გამოტოვება (ორიგინალის შენარჩუნება)**-ს, შედეგის მისაღებად — **გაგრძელება**-ს.

ოპტიმიზებული ფოტოდან იშლება ადგილმდებარეობისა და კამერის მონაცემები.

## 2. აირჩიეთ პარამეტრები

![არქივის პარამეტრები: ტეგების ტიპები](../assets/screenshots/android-archive-settings.png){ width="300" }
![არქივის პარამეტრები: ოფციები და შეფასება](../assets/screenshots/android-archive-estimate.png){ width="300" }

- **NFC ტეგის ტიპი**: ტეგების სახეობა, რომლებზეც ჩაწერთ. ნაგულისხმევად არჩეულია NTAG216. რამდენს იტევს თითოეული, იხ. [ტეგების ტიპები](tag-types.md). Mifare Classic 1K სიაში მხოლოდ მაშინ ჩანს, როცა თქვენს წამკითხველს მისი ჩაწერა შეუძლია (Mifare-ის მხარდაჭერით Android ტელეფონი ან [Chameleon Ultra](chameleon.md)).
- **შეკუმშვის ჩართვა** (არჩევითი): GZIP შეკუმშვა. ის მხოლოდ მაშინ გამოიყენება, თუ მონაცემებს მართლაც ამცირებს; უკვე შეკუმშული ფაილები, როგორიცაა ფოტოები, ვიდეოები ან ZIP, თითქმის არ მცირდება.
- **დაშიფვრის ჩართვა** (არჩევითი): არქივს AES-256-GCM-ით იცავს. შეიყვანეთ **პაროლი**. პაროლი არსად ინახება: მის გარეშე არქივის აღდგენა შეუძლებელია, ამიტომ არ დაკარგოთ.

ქვემოთ **არქივის შეფასება** აჩვენებს, რამდენი ტეგი გჭირდებათ (**საჭირო ტეგები**) და რამდენი ბაიტი მოხვდება თითოეულზე (**მონაცემები ტეგზე**). ეს შეფასებაა: შეკუმშვის შედეგი წინასწარ ივარაუდება.

შეეხეთ **არქივაციის დაწყება**-ს.

## 3. ჩაწერეთ ტეგები სათითაოდ

![ტეგებზე ჩაწერა](../assets/screenshots/android-write-progress.png){ width="300" }

თითოეული ტეგისთვის:

1. შეეხეთ **ტეგზე ჩაწერა**-ს.
2. მიადეთ ტეგი ტელეფონს (iPhone-ზე, როცა NFC ფანჯარა გამოჩნდება; იხ. [iPhone-ზე](iphone.md)).
3. დაელოდეთ **ტეგი ჩაწერილია!**-ს, შემდეგ აიღეთ ტეგი.

პროგრესის ზოლი ჩაწერილ ტეგებს ითვლის. ბოლოს დასრულების შემდეგ დაინახავთ **არქივაცია დასრულებულია!**-ს.

ტეგები მოგვიანებით ნებისმიერი თანმიმდევრობით შეიძლება დასკანერდეს, ამიტომ მათი დანომვრა საჭირო არ არის. მაგრამ შეინახეთ ერთად: ფაილის აღსადგენად ყველა ტეგია საჭირო.

!!! warning "ამ ტეგის გამოტოვება"
    **ამ ტეგის გამოტოვება** შემდეგ ნაწილზე გადადის მიმდინარის *ჩაწერის გარეშე*. გამოტოვებული ნაწილის მქონე არქივი ვერ აღდგება: გამოტოვებული ნაწილის მოგვიანებით ჩაწერა შეუძლებელია. აღდგენადი არქივისთვის ფაილი თავიდან უნდა დააარქივოთ.

## თუ ტეგი ძალიან პატარაა { #if-a-tag-is-too-small }

რეალურ ტეგებს ზოგჯერ ოდნავ ნაკლები ადგილი აქვთ, ვიდრე მათი ტიპი გვპირდება. თუ ტეგი ნაწილს ვერ იტევს, აპი აჩვენებს **ტეგი ძალიან პატარაა**-ს ტეგზე არსებული და ნაწილისთვის საჭირო ადგილით:

- თუ ჯერ არც ერთი ტეგი არ ჩაწერილა, შეგიძლიათ შეეხოთ **ხელახლა კონფიგურაცია**-ს: აპი მონაცემებს ამ ტეგზე მორგებულ უფრო პატარა ნაწილებად დაყოფს და გეტყვით, რამდენი ტეგია ახლა საჭირო.
- სხვა შემთხვევაში (ან თუ გირჩევნიათ) შეეხეთ **სხვა ტეგის გამოყენება**-ს და მიადეთ უფრო დიდი ტეგი.

პირველი ტეგის ჩაწერის შემდეგ არქივის ხელახლა კონფიგურაცია აღარ შეიძლება.

თუ არჩეულისგან განსხვავებული სახეობის ტეგს მიადებთ (მაგალითად, Mifare Classic ბარათს, როცა არჩეულია NTAG216), აპი ამას გეტყვით; დაბრუნდით უკან და შეცვალეთ **NFC ტეგის ტიპი**.
