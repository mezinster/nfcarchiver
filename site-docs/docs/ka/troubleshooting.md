# პრობლემების გადაჭრა

შეცდომის ზოგიერთ შეტყობინებას აპი ჯერჯერობით მხოლოდ ინგლისურად აჩვენებს; აქ ისინი მოცემულია ისე, როგორც არის, თარგმანით.

## ტეგის მიდებისას არაფერი ხდება

- **Android:** შეამოწმეთ, რომ NFC ჩართულია. თუ მთავარ ეკრანზე წერია **NFC მიუწვდომელია**, NFC გამორთულია ან ტელეფონს არ აქვს.
- **iPhone:** დაელოდეთ NFC ფანჯარას. ყოველი ტეგის შემდეგ შემდეგი ფანჯარა დაახლოებით 3 წამში იხსნება. თუ სკანირება შეჩერდა (გაუქმების ან 60-წამიანი ლიმიტის შემდეგ), შეეხეთ **მეტი ტეგის სკანირება**-ს.
- ანტენის საპოვნელად ნელა გადაატარეთ ტეგი ტელეფონის უკანა მხარეს და გეჭიროთ უძრავად. სქელმა ან ლითონის ქეისმა შეიძლება NFC დაბლოკოს.
- თუ [Chameleon Ultra](chameleon.md) დაკავშირებულია, დადეთ ტეგი Chameleon-ზე და არა ტელეფონზე.
- ზედიზედ ხუთი წარუმატებელი წაკითხვის შემდეგ სკანირება ჩერდება; გასაგრძელებლად შეეხეთ **მეტი ტეგის სკანირება**-ს.

## iPhone: ფანჯარა ძახილის ნიშნით დაიხურა

ძახილის ნიშანი ნიშნავს, რომ ტეგი დუბლიკატია (უკვე დასკანერებული) ან ვერ წაიკითხა. დაახლოებით 3 წამში ახალი ფანჯარა გაიხსნება; მიადეთ შემდეგი ტეგი, ან იგივე კიდევ ერთხელ, თუ ვერ წაიკითხა. იხ. [iPhone-ზე](iphone.md).

## ტეგი ძალიან პატარაა

ტეგს ნაწილისთვის საჭიროზე ნაკლები ადგილი აქვს. პირველი ტეგის ჩაწერამდე შეგიძლიათ შეეხოთ **ხელახლა კონფიგურაცია**-ს, რომ არქივი უფრო პატარა ნაწილებად დაიყოს; სხვა შემთხვევაში შეეხეთ **სხვა ტეგის გამოყენება**-ს. იხ. [ფაილის დაარქივება](archive.md#if-a-tag-is-too-small).

## "Tag is not writable"

„ტეგზე ჩაწერა შეუძლებელია“: ტეგი დაბლოკილია (მხოლოდ წასაკითხად). გამოიყენეთ სხვა ტეგი.

## "Tag does not support NDEF"

სრული შეტყობინება: "Tag does not support NDEF. Please use a pre-formatted NDEF tag." („ტეგი NDEF-ს არ უჭერს მხარს. გამოიყენეთ NDEF-ზე დაფორმატებული ტეგი.“) NTAG ტეგები NDEF-ზე უნდა იყოს დაფორმატებული; ახალი ტეგები ჩვეულებრივ უკვე ასეა. გამოიყენეთ სხვა ტეგი.

iPhone-ზე იგივე შეტყობინება Mifare Classic ბარათზეც ჩნდება. iPhone-ის ჩაშენებულ NFC-ს ამ ბარათების გამოყენება არ შეუძლია; გამოიყენეთ [Chameleon Ultra](chameleon.md).

## "Couldn't read the tag"

"Couldn't read the tag — hold it still against the phone and try again." („ტეგის წაკითხვა ვერ მოხერხდა — გეჭიროთ ის უძრავად ტელეფონთან და კვლავ სცადეთ.“) ტეგი ძალიან ადრე აიღეს. გეჭიროთ უძრავად, სანამ აპი არ რეაგირებს.

## "Tag does not contain valid archive data"

„ტეგზე არქივის სწორი მონაცემები არ არის“: ტეგი ცარიელია ან შეიცავს რაღაცას, რაც NFC Archiver-ს არ ჩაუწერია.

## „ეს არის … ბარათი, მაგრამ ეს არქივი კონფიგურირებულია …-სთვის“

მიდებული ტეგი არჩეული **NFC ტეგის ტიპი**-სგან განსხვავებული სახეობისაა. შეცვალეთ ტეგის ტიპი არქივის პარამეტრებში ან გამოიყენეთ სწორი ტეგები.

## "This looks like a Mifare Classic card. Your phone's NFC chip can't read them."

„როგორც ჩანს, ეს Mifare Classic ბარათია. თქვენი ტელეფონის NFC ჩიპს მათი წაკითხვა არ შეუძლია.“ თქვენს Android ტელეფონს Mifare Classic არ შეუძლია (მის NFC ჩიპს Mifare-ის მხარდაჭერა არ აქვს). გამოიყენეთ [Chameleon Ultra](chameleon.md).

## არასწორი პაროლი

"Decryption failed: wrong password or corrupted data" („გაშიფვრა ვერ მოხერხდა: არასწორი პაროლი ან დაზიანებული მონაცემები“). შეეხეთ **სხვა პაროლის ცდა**-ს. დიდ და პატარა ასოებს მნიშვნელობა აქვს (ჰარები დასაწყისსა და ბოლოში იგნორირდება), ხოლო დავიწყებული პაროლის აღდგენა შეუძლებელია.

## აღმოჩენილია მონაცემთა დაზიანება

ნაწილმა საკონტროლო ჯამის (CRC) შემოწმება ვერ გაიარა, ჩვეულებრივ იმიტომ, რომ ტეგი ცუდად წაიკითხა. შეეხეთ **1 ტეგის ხელახლა სკანირება**-ს (რიცხვი იცვლება) და ხელახლა დაასკანერეთ აპის მიერ მითითებული ტეგები. წარმატებული წაკითხვა დაზიანებულ ნაწილს ჩაანაცვლებს.

## ზოგიერთი ტეგი აკლია

სკანირების ეკრანზე **მიმდინარე არქივები** აჩვენებს, თითოეული არქივის რამდენი ტეგი გაქვთ (მაგალითად 5/8). პროგრესი ინახება, ასე რომ, დაკარგული ტეგების პოვნა და დასკანერება მოგვიანებითაც შეგიძლიათ.
