# ფაილის აღდგენა

აღსადგენად დაასკანერეთ არქივის ყველა ტეგი. თანმიმდევრობას მნიშვნელობა არ აქვს.

## 1. დაასკანერეთ ტეგები

მთავარ ეკრანზე შეეხეთ **არქივის აღდგენა**-ს. გაიხსნება ეკრანი **ტეგების სკანირება** და სკანირება დაიწყება.

![ტეგების სკანირება](../assets/screenshots/android-scan.png){ width="300" }

*გადაღებულია ემულატორში NFC-ის გარეშე, აქედან გაფრთხილება. ქვემოთ ორი არქივი სურათისთვის მომზადდა.*

მიადეთ თითოეული ტეგი ტელეფონს რიგრიგობით (iPhone-ზე თითო ტეგზე ერთი NFC ფანჯარა; იხ. [iPhone-ზე](iphone.md)):

- ახალი ტეგი აჩვენებს **ნაპოვნია ახალი ნაწილი!**-ს და თავის ნომერს, მაგალითად „ნაწილი 3 / 8“.
- უკვე დასკანერებული ტეგი აჩვენებს **დუბლიკატი ნაწილი**-ს და იგნორირდება. iPhone-ზე ფანჯარა იხურება წითელი ძახილის ნიშნით და შეტყობინებით „ნაწილი 3 / 8 უკვე დასკანერებულია“.

**მიმდინარე არქივები** აჩვენებს ყველა არქივს, რომლის სკანირებაც დაიწყეთ, და რამდენი ტეგი გაქვთ მისგან (მაგალითად 2/4). პროგრესი ინახება: შეგიძლიათ გახვიდეთ და მოგვიანებით დაბრუნდეთ დარჩენილი ტეგების დასასკანერებლად. სხვადასხვა არქივის ტეგები შეიძლება აირიოს; თითოეული თავის არქივში მოხვდება.

დაუსრულებელი არქივის სიიდან წასაშლელად შეეხეთ მის ✕-ს. ზემოთ ნაგვის ყუთის ხატულა მთელ სიას ასუფთავებს.

## 2. აღადგინეთ

როცა ბოლო ტეგიც დასკანერდება, აპი აჩვენებს **ყველა ნაწილი მიღებულია!**-ს.

- **ფაილის სახელი** (არჩევითი): დატოვეთ ცარიელი, რომ ორიგინალური სახელი გამოიყენოთ.
- თუ არქივი დაშიფრულია („ეს არქივი დაშიფრულია“), შეიყვანეთ **პაროლი**.

შეეხეთ **არქივის აღდგენა**-ს. თუ ჯერ კიდევ რამის დასკანერება გინდათ, **მეტი ტეგის სკანირება** უკან დაგაბრუნებთ.

აქ მოხვედრა ასევე შეიძლება **მიმდინარე არქივები**-ს სიაში დასრულებულ არქივზე (ნიშნით ✓) შეხებით.

## 3. გამოიყენეთ აღდგენილი ფაილი

![არქივი აღდგენილია](../assets/screenshots/android-restore-complete.png){ width="300" }

**არქივი აღდგენილია!** აჩვენებს ფაილის სახელს. მას ემატება არქივის იდენტიფიკატორის მოკლე ნაწილი, რომ სხვადასხვა არქივის ფაილებმა ერთმანეთი არასოდეს გადაწერონ. ფაილი აპის შიგნით ინახება, სადაც სხვა აპები მას ვერ ხედავენ. მის გამოსაყენებლად:

- **გახსნა** ხსნის მას აპში, რომელიც ამ ტიპის ფაილს ამუშავებს.
- **მოწყობილობაში შენახვა** ხსნის სისტემის შენახვის ფანჯარას (ნაგულისხმევად Downloads), რომ ასლი აპის გარეთ შეინახოთ.
- **ფაილის გაზიარება** აგზავნის მას სხვა აპში.

აღდგენილი ფაილები ასევე ჩანს მთავარ ეკრანზე, **არქივირებული ფაილები**-ში. ტექსტის არქივი ტექსტს პირდაპირ აჩვენებს, მისი კოპირების ღილაკით.

## თუ რამე არასწორად წავიდა

- **არასწორი პაროლი**: აპი წერს (ინგლისურად) "Decryption failed: wrong password or corrupted data". შეეხეთ **სხვა პაროლის ცდა**-ს და ხელახლა შეიყვანეთ.
- **აღმოჩენილია მონაცემთა დაზიანება**: რომელიმე ტეგის ნაწილმა საკონტროლო ჯამის (CRC) შემოწმება ვერ გაიარა. შეეხეთ **1 ტეგის ხელახლა სკანირება**-ს (რიცხვი იცვლება) და ხელახლა დაასკანერეთ მითითებული ტეგები; წარმატებული წაკითხვა დაზიანებულს ჩაანაცვლებს.
