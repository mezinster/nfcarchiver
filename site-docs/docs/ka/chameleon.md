# Chameleon წამკითხველი

[Chameleon Ultra](https://github.com/RfidResearchGroup/ChameleonUltra) არის პატარა, ჯიბის ზომის NFC წამკითხველი და ემულატორი. NFC Archiver-ს შეუძლია მისი გამოყენება **Bluetooth**-ით ტელეფონის ჩაშენებული NFC-ის ნაცვლად, როგორც iPhone-ზე, ისე Android-ზე.

## რატომ გამოვიყენოთ

- **Mifare Classic 1K ნებისმიერ ტელეფონზე.** Mifare Classic ბარათებს CRYPTO1 შიფრი სჭირდება. Chameleon მას საკუთარ ჩიპში ასრულებს, ამიტომ მუშაობს, როგორი ტელეფონიც არ უნდა გქონდეთ.
- **iPhone-ზე ეს Mifare Classic-ის გამოყენების ერთადერთი გზაა.** iPhone-ის ჩაშენებულ NFC-ს ამ ბარათების წაკითხვა და ჩაწერა საერთოდ არ შეუძლია.
- **ბარათის დათვალიერება.** დაკავშირებული Chameleon-ით **ბარათის დათვალიერება** აჩვენებს ბარათის შიგთავსს ბლოკ-ბლოკ. ტელეფონის ჩაშენებულ NFC-ს ბარათებზე პირდაპირი წვდომა არ აქვს, ამიტომ ამას Chameleon სჭირდება.

## დაკავშირება

1. ჩართეთ Chameleon და გეჭიროთ ტელეფონთან ახლოს.
2. ჩართეთ Bluetooth.
3. მთავარ ეკრანზე შეეხეთ ზედა ზოლში **წამკითხველის ხატულას** (NFC სიმბოლო, სანამ ტელეფონის NFC გამოიყენება). გაიხსნება ეკრანი **წამკითხველი**.
4. შეეხეთ **ძებნა**-ს, შემდეგ სიაში თქვენს Chameleon-ს.

პირველად ტელეფონი Bluetooth-ის ნებართვას მოითხოვს. აპი Bluetooth-ს მხოლოდ თქვენს Chameleon-თან კავშირისთვის იყენებს; Android-ზე ის თქვენს მდებარეობას არ ითხოვს.

დაკავშირების შემდეგ წამკითხველის ხატულა Bluetooth სიმბოლოს აჩვენებს, ხოლო **არქივის შექმნა** და **არქივის აღდგენა** Chameleon-ს იყენებს: დადეთ ტეგები Chameleon-ზე და არა ტელეფონზე. iPhone-ზე ამ რეჟიმში NFC ფანჯარა არ ჩნდება. ტეგების ტიპების სიაში ჩნდება **Mifare Classic 1K**.

ტელეფონის ჩაშენებულ NFC-ზე დასაბრუნებლად გახსენით ეკრანი **წამკითხველი** და შეეხეთ **გათიშვა**-ს.

## თუ ვერ მოიძებნა

- „Bluetooth გამორთულია. ჩართეთ Chameleon-ის გამოსაყენებლად.“: ჩართეთ Bluetooth.
- „Chameleon-ის მოსაძებნად საჭიროა Bluetooth-ის ნებართვა.“: ტელეფონის პარამეტრებში მიეცით NFC Archiver-ს Bluetooth-ის ნებართვა.
- სია სულ აჩვენებს „Chameleon-ის ძებნა…“: გააღვიძეთ Chameleon და მიუახლოვეთ. სუსტი Bluetooth სიგნალი ასევე ანელებს ყველა ოპერაციას.
- „Chameleon-თან დაკავშირება ვერ მოხერხდა.“: გამორთეთ და ჩართეთ Chameleon, შემდეგ კვლავ შეეხეთ **ძებნა**-ს.
