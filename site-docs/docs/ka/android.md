# Android-ზე

NFC-იანი Android ტელეფონი პირდაპირ წერს და კითხულობს **NTAG213, NTAG215 და NTAG216** ტეგებს. მას ასევე შეუძლია **Mifare Classic 1K**-ის პირდაპირ ჩაწერა და წაკითხვა, მაგრამ მხოლოდ მაშინ, თუ მისი NFC ჩიპი Mifare Classic-ს უჭერს მხარს (NXP-ის Mifare ფუნქცია). ყველა ტელეფონს ეს არ შეუძლია: სხვა მწარმოებლების ბევრ NFC ჩიპს ეს ფუნქცია არ აქვს.

აპი ამას თავად ამოწმებს. თუ თქვენს ტელეფონს Mifare Classic არ შეუძლია, **Mifare Classic 1K** ტეგების ტიპების სიაში უბრალოდ არ არის. [Chameleon Ultra](chameleon.md) მას ნებისმიერ ტელეფონზე ამატებს.

![მთავარი ეკრანი](../assets/screenshots/android-home.png){ width="300" }

*მთავარი ეკრანი (ეკრანის სურათები ინგლისურადაა). სურათი გადაღებულია ემულატორში NFC-ის გარეშე, ამიტომ ჩანს გაფრთხილება „NFC მიუწვდომელია“.*

## დაწყებამდე

- **ჩართეთ NFC** ტელეფონის პარამეტრებში. თუ NFC გამორთულია (ან ტელეფონს არ აქვს), მთავარ ეკრანზე წერია **NFC მიუწვდომელია**.
- **იპოვეთ ანტენა.** NFC ანტენის მდებარეობა ტელეფონზეა დამოკიდებული; ბევრ მოდელში ის უკანა მხარესაა, ზემოთ ახლოს. თუ არაფერი ხდება, ნელა გადაატარეთ ტეგი ტელეფონის უკანა მხარეს.
- გეჭიროთ ტეგი უძრავად, სანამ აპი არ რეაგირებს. ჩაწერის ან წაკითხვის შუაში აღებული ტეგი წარუმატებლობის ყველაზე ხშირი მიზეზია.

## როგორ მუშაობს Android-ზე

Android-ზე სისტემური ფანჯარა არ არის: პროგრესს აპის საკუთარი ეკრანი აჩვენებს.

- **ჩაწერისას** შეეხეთ **ტეგზე ჩაწერა**-ს, შემდეგ მიადეთ ტეგი ტელეფონს. **ტეგი ჩაწერილია!** ამას ადასტურებს. აიღეთ ტეგი და შემდეგისთვის კვლავ შეეხეთ **ტეგზე ჩაწერა**-ს.
- **სკანირებისას** მიადეთ ტეგები რიგრიგობით. ყოველი ახალი აჩვენებს **ნაპოვნია ახალი ნაწილი!**; უკვე დასკანერებული — **დუბლიკატი ნაწილი**.

თუ Mifare-ის მხარდაჭერის არმქონე ტელეფონს Mifare Classic ბარათს მიადებთ, აპი (ჯერჯერობით ინგლისურად) გეტყვით: "This looks like a Mifare Classic card. Your phone's NFC chip can't read them." („როგორც ჩანს, ეს Mifare Classic ბარათია. თქვენი ტელეფონის NFC ჩიპს მათი წაკითხვა არ შეუძლია.“)
